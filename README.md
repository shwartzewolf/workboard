# Workboard for Windows

Workboard helps teams manage projects and tasks in shared boards. The Windows setup wizard installs a launcher, an offline workspace, and a PDF user manual.

- [Download the Windows installer](https://github.com/shwartzewolf/workboard/releases/latest/download/Workboard-Setup.msi)
- [Download the user manual (PDF)](https://github.com/shwartzewolf/workboard/releases/latest/download/Workboard-User-Manual.pdf)
- [Release notes and SHA-256 checksums](https://github.com/shwartzewolf/workboard/releases/latest)

Use 64-bit Windows 10 or 11. The installer is unsigned, so Windows may show an unknown publisher warning. Setup installs Workboard for your Windows user and offers an optional desktop shortcut.

Open **Workboard** from Start for the shared workspace. Sign in with a Microsoft Entra work account assigned access by your Workboard admin. You can also open **Workboard Offline** and save boards in your browser profile on this PC. Use **Data & backup** in the offline workspace to export a copy.
